# Sleep Cycle Calculator

A production-ready Next.js 14 sleep cycle and bedtime/wake-up calculator. It uses 90-minute cycle estimates plus a 14-minute average fall-asleep window.

## Features

- Sleep now, target wake time, and planned bedtime modes
- Highlights five- and six-cycle schedules
- One-click plan copy
- 192 statically generated time landing pages at 15-minute intervals
- FAQ and WebApplication structured data
- Fixed-domain sitemap, robots, canonical URLs, and Google verification

## Development

```bash
npm install
npm run dev
```

Validation:

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

## Disclaimer

This calculator is educational and is not medical advice. Sleep cycles vary by person and throughout the night.
